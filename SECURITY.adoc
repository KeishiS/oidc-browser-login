= セキュリティーポリシー

== 脆弱性の報告

脆弱性を公開Issueへ記載しないでください。GitHubの
https://github.com/KeishiS/oidc-browser-login/security/advisories/new[非公開の脆弱性報告]
から、影響するversion、再現方法、想定される影響を連絡してください。

修正版はこのリポジトリで公開します。利用側は修正commitへ依存revisionを更新し、
自身の契約試験と結合試験を実行してください。

== 署名アルゴリズムの既定とRUSTSEC-2023-0071

ID tokenの署名検証に許可するアルゴリズムは、既定でES256(楕円曲線P-256のECDSA)だけです。
依存する``rsa`` crateには、秘密鍵の操作で処理時間から鍵の情報が漏れうる既知の脆弱性
RUSTSEC-2023-0071(Marvin attack)がありますが、このライブラリーは次の理由で影響しないと
判断し、``cargo audit``の除外に登録しています。

* 既定のES256ではRSAのコードを実行しません。
* RS256を明示的に許可した場合も、行うのはIdPの公開鍵による署名検証だけで、秘密鍵の操作を
  含みません。RUSTSEC-2023-0071が問題にするのは秘密鍵操作の処理時間です。

RS256の許可(``OidcSettings::with_allowed_algorithms``)を使う利用側は、この判断が自身の
配備にも当てはまるかを確認してください。また、依存の更新でRSAの利用範囲が変わった場合は、
この除外の妥当性を再評価します。

== 試験用鍵について

``oidc-browser-login-testkit``には疑似IdPの署名鍵が平文で含まれます。これは試験専用に
公開している鍵であり、secretではありません。実配備で使わないでください。testkitを
production依存に含めないでください。
